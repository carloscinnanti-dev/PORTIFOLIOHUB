
# PortfolioHUB 

Bem-vindo ao repositório do **PortfolioHUB**, uma plataforma centralizada para exibir e gerenciar projetos e portfólios digitais. Este projeto foi implantado seguindo práticas recomendadas de segurança, controle de versão e contou com o apoio do **Google GEMINI** como guia estratégico.

---

##  Planejamento da Implantação
A trilha de implantação foi estruturada com o suporte da Inteligência Artificial Google GEMINI, dividindo o projeto nas seguintes etapas:
1. Configuração do ambiente no GitHub e ativação do GitHub Pages.
2. Implementação de regras de acesso e segurança de branch.
3. Organização dos arquivos e preparação para o ambiente de produção.

##  Gestão de Usuários e Segurança
Para garantir a conformidade e a proteção do código, foram aplicadas as seguintes configurações:
* **Proteção de Branch:** Restrição da branch principal (`main`) para evitar alterações acidentais.
* **Monitoramento:** Ativação dos alertas de segurança nativos do GitHub (Dependabot) para análise de vulnerabilidades.
